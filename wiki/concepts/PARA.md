# PARA

**PARA** คือระบบจัดระเบียบไฟล์ 4 โฟลเดอร์จาก Tiago Forte (หนังสือ *Building a Second Brain*): **Projects, Areas, Resources, Archives** — จัดหมวดตามระดับ "ความเคลื่อนไหว" ของงาน

## โครงสร้าง
- **Projects** — งานที่มีเป้าหมายและกำหนดส่งชัดเจน
- **Areas** — ความรับผิดชอบที่ต้องดูแลต่อเนื่อง (ไม่มีจุดสิ้นสุด)
- **Resources** — ข้อมูลอ้างอิง/ความสนใจ
- **Archives** — งานเก่าที่ไม่เคลื่อนไหวแล้ว

## จุดอ่อนที่ Tim Miller พบ (ในฐานะผู้ใช้จริง)
- ใช้ PARA มาหลายปีแต่ไม่เวิร์กกับตัวเอง — สับสนระหว่าง Projects กับ Areas และพบว่า Resources "nebulous" เกินไป
- **เก็บไว้เพียงโฟลเดอร์เดียวคือ Archives** เพราะได้ประโยชน์จาก "เริ่มใหม่แบบโล่งๆ แต่ไม่ลบทิ้งอะไร"
- จึงออกแบบระบบของตัวเองเป็น [[wiki/syntheses/FINVA Folder Structure|FINVA]] (Fleeting → In Progress → Notes → Views → Archives)

## บทเรียน
- ระบบจัดระเบียบต้อง "เวิร์กกับคุณ" ไม่ใช่ต้องปรับตัวเข้ากับระบบที่นิยม — เป็นตัวอย่างการทดลองแล้วปรับแต่ง (iterate) วิธีทำงานจริง

## มุมมองเพิ่มเติม
- CyanVoxel ใช้ PARA ร่วมกับ [[wiki/concepts/Zettelkasten|Zettelkasten]]: PARA จัดการ "ชีวิตจริง" (โปรเจกต์/พื้นที่/ทรัพยากร/คลัง) ส่วน Zettelkasten ดูแล "ความรู้เชิงลึก" — แล้วเชื่อมทั้งคู่ด้วย MOCs (ดู [[wiki/syntheses/CyanVoxel Vault System|CyanVoxel Vault System]])
