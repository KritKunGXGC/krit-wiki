# Obsidian

**Obsidian** คือแอปจดโน้ต/จัดการความรู้ (PKM) แบบ local-first เปิดตัว **2020** ในกระแส second brain — เก็บโน้ตเป็นไฟล์ **Markdown บนเครื่อง** ไม่ต้องมี account/cloud และจุดเด่นคือ **bidirectional linking** + Graph View

## จุดเด่น
- **โน้ต = ไฟล์ของคุณจริงๆ** — Markdown ธรรมดา เปิดด้วย text editor ไหนก็ได้; ไม่ถูกขังในบริการ (ต่างจาก Notion/Evernote/Roam)
- **Bidirectional linking** — เชื่อมโน้ตถึงกันเป็น \"web\" ของความรู้ส่วนตัว พร้อม Graph View ที่ visualize ความสัมพันธ์
- **Ecosystem plugins 1,500+** — calendar, flashcards, task management, AI tools, database (Bases), automation (Templater/Dataview)...
- ตรงข้ามกระแสปี 2026 ที่แม้แต่แอปเครื่องคิดเลขยังอยากได้ account — Obsidian ให้ผู้ใช้ควบคุมข้อมูลของตัวเอง

## ปรัชญาการใช้ (จากแหล่งใน vault)
- **Plugins แบบ unobtrusive** — เลือกน้อยแต่เพิ่ม quality of life; ระวัง 3 หลุมพราง: ความซับซ้อนเกินจำเป็น, support หยุด, Markdown ไม่บริสุทธิ์ (ดู [[wiki/syntheses/Essential Obsidian Plugins|Essential Obsidian Plugins]])
- **โฟลเดอร์ = workflow, ลิงก์ = organization** — โฟลเดอร์ 5 อัน (FINVA) ดูแล \"สถานะ\" ของโน้ต ส่วนการจัดหมวดทำผ่าน MOC/Bases/ลิงก์ (ดู [[wiki/concepts/PARA|PARA]], [[wiki/concepts/Bases|Bases]])
- **Theming เป็นเครื่องมือ** — CSS snippets แบบ class-based ปรับได้ลึกโดยไม่รบกวนโน้ตอื่น (ดู [[wiki/syntheses/CyanVoxel Vault System|CyanVoxel Vault System]])
- **AI เข้ามาเสริม** — agent อ่าน/เขียนโน้ตได้ผ่าน skill + ระบบควบคุมการเข้าถึง 3 ชั้น (skills / Docker mount / system) (ดู [[wiki/sources/Obsidian Agentic AI Workflow|Obsidian Agentic AI Workflow]])
