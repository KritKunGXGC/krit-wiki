# What is OpenClaw Published

**วันที่:** 2026-07-01

## สรุป
[[wiki/entities/Tech With Lucy|Tech With Lucy]] เผยแพร่วิดีโอ "What is OpenClaw? Explained for Beginners" — อธิบายเฟรมเวิร์ก AI agent แบบ open-source ที่ทำงาน 24/7

## รายละเอียด
- อธิบายความต่างระหว่างแชทบอท (ChatGPT/Claude) กับ autonomous agent (OpenClaw) — ตั้งแต่การทำงานบนเครื่องของคุณ ไปจนถึง persistent memory
- ตัวอย่างการใช้งานจริง: second brain, personal dashboard, การต่อรองซื้อรถอัตโนมัติ (ลดราคาได้ $4,000+)
- ครอบคลุมจุดเริ่มต้น (ใช้เวลา ~10 นาที) และความเสี่ยงด้านความปลอดภัย (malicious skills, exposed agents, prompt injection)
