# ElevenLabs Site Snapshot

**วันที่:** 2026-05-28

> หมายเหตุ: วันที่นี้มาจาก field `published` ของ web clipper สำหรับหน้าแรก (elevenlabs.io) — เป็นวันที่ snap ของเนื้อหาเว็บ ไม่ใช่วันประกาศ release อย่างเป็นทางการ

## สรุป
snapshot ของหน้าเว็บ ElevenLabs ณ วันที่นี้ — แสดงระบบนิเวศ AI เสียงเต็มรูปแบบ: Creative, Agents และ API พร้อมไทม์ไลน์โมเดลล่าสุด

## รายละเอียด
- **ElevenCreative** — สร้าง speech/วิดีโอ/เพลง/SFX แบบเรียลลิสติก 70+ ภาษา
- **ElevenAgents** — voice agents แบบ omnichannel (โทรศัพท์/แชท/อีเมล/WhatsApp)
- **ElevenAPI** — TTS (Eleven Flash 75ms), STT (Scribe 98%), Music API
- ไทม์ไลน์โมเดล ณ จุดนี้ครอบคลุมถึง **Music v2 และ Dubbing v2** (พ.ค. 2026)
