# Asylum

Asylum เป็น YouTube creator ในรูปแบบ **"Every X Explained"** — ผลิตวิดีโออธิบายเทคโนโลยีและเครื่องมือดิจิทัลแบบรวบรัดในเวลาสั้น เน้นการใช้งานจริง ทางเลือกฟรี/open source และการแปลศัพท์เทคนิคให้เข้าใจง่าย

## ภาพรวมช่อง
- **รูปแบบ:** วิดีโอสรุปหัวข้อใหญ่ทีละหมวดเดียวจบ (เช่น "Every Free App...", "Every Web Browser Explained", "Every AI Model Explained") — รวบรวมเป็นรายการให้จำง่าย
- **ธีมเนื้อหา:** ซอฟต์แวร์ฟรีทดแทนซอฟต์แวร์เสียเงิน, เครื่องมือดิจิทัล, การลดค่าใช้จ่ายด้วย open source
- **ขนาดช่อง:** ผู้ติดตามหลักหมื่นปลาย ๆ (ประเมินจาก public analytics trackers โดยประมาณ)
