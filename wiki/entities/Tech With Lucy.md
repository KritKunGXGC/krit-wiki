# Tech With Lucy

Tech With Lucy (Lucy Wang) เป็น YouTuber ด้าน cloud computing และ AI — อดีต **AWS Solutions Architect** (ประสบการณ์คลาวด์ 5+ ปี), ผู้ก่อตั้ง **Zero To Cloud** และ AWS Community Builder

## ภาพรวม
- **พื้นหลัง:** อดีต AWS Solutions Architect → ผันมาให้ความรู้ cloud/AI แก่ผู้เริ่มต้น; ผู้ติดตาม ~274K (YouTube) + ฐานผู้ติดตามมืออาชีพบน LinkedIn 250K+
- **ธีมเนื้อหา:** AWS, serverless, เส้นทางอาชีพสายคลาวด์, เตรียมสอบใบรับรอง (AWS certs) และ AI/ML — รวมถึง AI agent frameworks
- **รูปแบบ:** อธิบายเป็นขั้นเป็นตอน เน้น "รู้แล้วทำได้เลย"
