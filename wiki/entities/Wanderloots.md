# Wanderloots

Wanderloots (Callum) เป็น content creator, writer และ "digital gardener" — อดีตทนายความทรัพย์สินทางปัญญา/patent agent ที่มีพื้นหลังวิศวกรรม ผันตัวมาสร้างคอนเทนต์เต็มเวลาและ build in public

## ภาพรวม
- **พื้นหลัง:** เรียนวิศวกรรม → ทำงานสาย IP law → full-time digital creator; ผู้ติดตาม ~92K (YouTube)
- **ธีมเนื้อหา:** local AI, agentic workflows, agentic memory และการผสาน AI เข้ากับ PKM อย่างปลอดภัย — สไตล์วิดีโอ essay ผสมเทคนิค
- **จุดเด่น:** Deep-dive การตั้งค่า **Hermes agent** — เชื่อม memory loop ในเครื่อง, จัดการ Docker เพื่อให้ agent ทำงานปลอดภัย และ sync ความทรงจำของ agent กลับสู่ Markdown vault
