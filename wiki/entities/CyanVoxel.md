# CyanVoxel

CyanVoxel (Travis Abendshien) เป็น software engineer — พื้นหลังเกมเดเวลอปเมนต์, web design และ utility apps (self-described **"jack of all trades, master of scrum"**) — ที่ทำคอนเทนต์เชิงลึกด้าน Obsidian: vault tours, CSS themes และการสร้างระบบ PKM ส่วนตัว

## ภาพรวม
- **พื้นหลัง:** Software engineer; เปิดตัวตนหลักบน GitHub + วิดีโอ vault tour บน YouTube
- **ธีมเนื้อหา:** การตกแต่ง vault (theming), CSS snippets, โครงสร้างโน้ต, ประสบการณ์ใช้งานจริง
- **Open source:** โปรเจกต์ Obsidian หลายชุดเผยแพร่บน GitHub ให้ชุมชนนำไปใช้

## Open-Source Projects (GitHub)
- **Vauxhall** — ธีมมืดสไตล์ medieval/deep-space ใช้ร่วมกับ Style Settings plugin
- **Obsidian Vault Template** — เทมเพลต vault คู่กับวิดีโอ tour
- **Obsidian Daily Themes / Game Themes** — CSS snippets สลับสีตามวันในสัปดาห์ หรือธีมเกม (Minecraft, Old School RuneScape)
- **Obsidian-Colored-Sidebar, Obsidian-Notebook-Themes** — snippets ที่กล่าวถึงในวิดีโอ tour 2024
- **TagStudio** — ระบบจัดการภาพ/เอกสาร (นอก Obsidian)
