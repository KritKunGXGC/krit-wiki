# What is OpenClaw Explained for Beginners

## Overview
OpenClaw is an open-source AI agent framework designed as an autonomous, 24/7 virtual assistant. Unlike traditional chatbot interfaces like ChatGPT, it runs continuously on your machine or cloud server.

## Key Features
- **Continuous Execution:** Runs in the background (local or cloud).
- **Communication Interface:** Uses existing apps like WhatsApp, Telegram, Discord, Slack, and iMessage.
- **Persistent Memory:** Remembers user preferences, contacts, and session history.
- **Task Automation:** Performs actions beyond research, such as booking hotels, making purchases, and managing calendars.

## Security Considerations
- **Malicious Skills:** Risk of malicious community-created "skills" (12% of Claw Hub marketplace items found to be malicious).
- **Exposed Agents:** Danger of leaving agents improperly secured and accessible on the internet.
- **Prompt Injection:** Vulnerability to attacks that manipulate agent instructions (e.g., "Claw Jacked").
- **Recommendation:** Run agents on a secure VPS rather than the local machine to isolate sensitive files and credentials.

## Getting Started
- Requires: A machine (laptop or VPS) and an API key (e.g., Claude, OpenAI, Gemini).
- Setup: Requires running a terminal command to install and configure.
