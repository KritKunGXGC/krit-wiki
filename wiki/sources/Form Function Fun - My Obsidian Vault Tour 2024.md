## Summary
วิดีโอ tour vault ของ CyanVoxel (2024-03-17) — เปิดเผยการตั้งค่า 3 ด้าน: การตกแต่ง appearance (ธีม + CSS snippets), 17 plugins, และระบบองค์กรที่ผสม Zettelkasten + PARA + MOCs

## Key Points

### Appearance & Theming
- ธีม: **vanilla AMOLED** + ฟอนต์ **JetBrains Mono Nerd** (monospace ทั้ง note + interface)
- CSS Snippets ที่แชร์บน GitHub:
  - **Colored Sidebar** — แต่ละ top-level folder มีสีเดียว cascade ลงลูกหลาน (hardcoded ต้องปรับเอง)
  - **General Tweaks** — ขอบมน, margin/border, คลาสต่อโน้ต (กรอบรูป, จัดกลางรูป/หัวข้อ)
  - **Notebook Themes** — ธีมกระดาษ/ปากกาจำลองสมุดจริง (Manila, whiteboard, index cards) + recolor รูปตามสีปากกา
  - **Daily Note Themes** — 7 สีตามวันในสัปดาห์ ผ่าน Templater ใส่ class ให้ daily note อัตโนมัติ
  - **Game Themes** — Minecraft, RuneScape (ต้องใช้ third-party fonts)

### Plugins (17 ตัว)
- **Core**: Daily Notes (YYYY-MM-DD), Unique Notes (สร้าง ID + frontmatter)
- **Community**: Calendar, Excalidraw, Spaced Repetition (flashcards), Advanced Slides (สคริปต์ YouTube), Templater, Iconize, Smart Typography (typographic quotes/apostrophes), Homepage, Recent Files, Completr, Paste URL Into Selection, Text Format, Tag Wrangler, Settings Search, Importer

### Organization: Zettelkasten + PARA + MOCs
- **Zettelkasten**: fleeting (ความคิดดิบ) → literature (ของคนอื่น) → permanent (กลั่นแล้ว) + การ linking ระหว่างกัน
- **PARA**: Projects (มี deadline) / Areas (ต่อเนื่อง) / Resources (ของคนอื่น) / Archives (จบแล้ว)
- **ระบบของเขา**: MOCs เป็น homepage ลิงก์กลุ่มโน้ต + daily notes + meta categories — "ระบบที่ใช้ต้องเติบโตตามความต้องการ ไม่ใช่ยึดติดวิธีเดียว"
