## Summary
วิดีโอโดย Just Explained (2026-08-08) อธิบายภาษาโปรแกรมหลัก 12 ภาษาแบบง่ายๆ ตั้งแต่วัตถุประสงค์ ที่มาของชื่อ ไปจนถึงตัวอย่างการใช้งานจริง พร้อมปิดท้ายด้วยหัวข้อ Vibe Coding ในยุค AI

## Key Points

### ภาษาโปรแกรมหลัก
| ภาษา            | ปี/ผู้สร้าง                      | ใช้ทำอะไร                                 | จุดเด่น/ข้อสังเกต                                                              |
| --------------- | -------------------------------- | ----------------------------------------- | ------------------------------------------------------------------------------ |
| **Python**      | 1991, Guido van Rossum           | AI, data science, เว็บ, automation        | อ่านง่ายเหมือน English; ช้าแต่เขียนเร็ว; ภาษาหมายเลข 1 ของ AI boom             |
| **JavaScript**  | 1995, Brendan Eich (10 วัน!)     | เว็บ interactive                          | ภาษาของอินเทอร์เน็ต; ชื่อมาจากการตลาด (ไม่เกี่ยวกับ Java); messy               |
| **TypeScript**  | 2012, Microsoft                  | เว็บขนาดใหญ่                              | เพิ่ม types เหนือ JS; 2025 กลายเป็นภาษาที่ใช้มากสุดบน GitHub                   |
| **Java**        | 1995, James Gosling (Sun)        | ระบบแบงก์/สายการบิน, Android              | "Write once, run anywhere" ผ่าน JVM; wordy แต่โครงสร้างดีสำหรับทีมใหญ่         |
| **C**           | 1972, Dennis Ritchie (Bell Labs) | OS, embedded, Mars rovers                 | ใกล้เครื่องระดับล่างสุด, เร็วมาก; ต้นตอของภาษาแทบทุกภาษา                       |
| **C++**         | 1983, Bjarne Stroustrup          | Game engine (Unreal), Chrome, trading     | C + organization; ชื่อ = C+1                                                   |
| **C#**          | 2000, Microsoft                  | Unity (เกม), Windows apps                 | คำตอบของ MS ต่อ Java; เกือบถูกเรียกว่า "Cool"                                  |
| **Rust**        | 2010s, Mozilla                   | ระบบปลอดภัย                               | Borrow checker กัน bug; "most loved" 9 ปีซ้อน; รัฐบาลสหรัฐฯ แนะนำย้ายจาก C/C++ |
| **Go**          | 2009, Google                     | Cloud infrastructure (Docker, Kubernetes) | วิธีเดียวในการเขียน (one way); เร็วในการ build                                 |
| **PHP**         | 1994, Rasmus Lerdorf             | เว็บ backend (70% ของเว็บ, WordPress)     | เริ่มจากแค่ตัวนับผู้เยี่ยมชม; ถูกแซวแต่ใช้งานมหาศาล                            |
| **HTML/CSS**    | 1991, Tim Berners-Lee            | โครงสร้าง + สไตล์ของเว็บ                  | ไม่ใช่ programming language จริง (ไม่มี logic); skeleton + paint               |
| **Vibe Coding** | 2025+                            | เขียนโค้ดด้วย AI จากคำอธิบาย              | 41% ของโค้ดใหม่ใน 2026 เขียนโดย AI; "ภาษาที่ฮอตที่สุดคือ English"              |

### ประเด็นสำคัญ
- **ทำไมต้องเรียนภาษาในยุค AI?** — เพราะ AI ยังพลาดบ่อย; ต้องรู้เพื่อจับผิด และ logic/โครงสร้างความคิดคือฐานของ programmer ที่ดี
- บทบาทเปลี่ยน: พิมพ์เองทุกบรรทัด → สั่ง AI + ตรวจสอบผลลัพธ์
