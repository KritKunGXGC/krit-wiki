## Summary
วิดีโอโดย Asylum (2026-06-09) แนะนำชุดซอฟต์แวร์ฟรี/open-source ที่ใช้แทนโปรแกรมเสียเงินมูลค่าหลายพันดอลลาร์/ปี — ครอบคลุม 12 เครื่องมือ ตั้งแต่ office, media player, video editing ไปจนถึง game engine

## Key Points

### หลักการ
- คนส่วนใหญ่จ่ายค่าซอฟต์แวร์ >$1,000/ปี โดยไม่รู้ตัว (Office, Photoshop, Premiere Pro, cloud storage)
- เกือบทั้งหมดมีทางเลือกฟรีที่ "ดีจริง" — การแลกเปลี่ยนคือเวลาเรียนรู้ที่มากขึ้นแทนการจ่ายเงิน

### เครื่องมือที่แนะนำ
| เครื่องมือ | แทนที่ | จุดเด่น |
|---|---|---|
| **LibreOffice** | MS Office ($100/ปี) | Writer/Calc/Impress, เปิดไฟล์ Office ได้, ไม่มี telemetry; รัฐบาลฝรั่งเศส/อิตาลีใช้ |
| **VLC Media Player** | ผู้เล่นมีเดียทั่วไป | เล่นได้แทบทุก format, <50MB, แปลงไฟล์/สตรีม/อัดหน้าจอ |
| **DaVinci Resolve** | Premiere Pro + After Effects | ตัดต่อ+VFX+เสียง+Color grading (John Wick, La La Land, Deadpool), ฟรี 95% |
| **OBS Studio** | XSplit, Camtasia ($60+) | Scene-based live production, มาตรฐานวงการสตรีม |
| **GIMP** | Photoshop ($260/ปี) | Raster editor ครบ (แต่ UI เก่า, ไม่มี CMYK native) |
| **Audacity** | Adobe Audition ($95–240) | Multi-track audio, VST/LV2 plugins |
| **Blender** | Maya, Cinema 4D, ZBrush | 3D pipeline ครบ (Spider-Verse, Next Gen), Cycles/Eevee |
| **Obsidian** | Notion, Evernote, Roam | โน้ต Markdown ท้องถิ่น, bidirectional linking, 1,500+ plugins |
| **Scratch** | คอร์สเรียนโค้ดเสียเงิน | Visual blocks, 100M+ projects, MIT Media Lab |
| **Godot** | Unity/Unreal (royalties) | MIT license ไม่เก็บค่าใช้จ่าย, 2D/3D, GDScript/C# |
| **HandBrake** | Movavi, Wondershare | แปลง/บีบอัดวิดีโอ |
| **7-Zip** | WinRAR | เปิดได้ทุก format, ฟรีจริง |

### หมายเหตุ
- จุดอ่อนของฟรีซอฟต์แวร์: learning curve สูง (Resolve, Blender), บางส่วน UI เก่า (GIMP), บางกรณี feature ขั้นสูงต่างกัน (Excel macros)
- 2026: แม้แต่แอปเครื่องคิดเลขยังอยากให้สมัคร account — ฟรีซอฟต์แวร์ที่ local/offline กลายเป็นของหายาก
