# Raw Sources Folder (`raw/`)

This folder is the designated repository for all your raw source files.

## How to use:
1. Drop any source material (clippings, PDFs, markdown notes, transcribed podcasts, web articles) into this folder.
2. Ask the LLM to **ingest** the file.
3. The LLM will parse the content, extract the essential information, and integrate it into the `wiki/` folder.

**Note:** Files in this folder are read-only to the LLM; they represent the permanent source of truth.
